# Security policy

Please report vulnerabilities privately, not in a public issue:

- GitHub private vulnerability reporting on this repository (Security tab → "Report a
  vulnerability"), or
- email hunter@veilcore.org with a subject starting "SECURITY".

Include the version or commit, what an attacker can do, and the input or steps that show
it. A failing conformance vector or test is the fastest route to a fix.

We acknowledge within three business days and send an assessment within a further five,
and credit reporters unless asked not to.

The VeilCore contract, operator tool and full incident process are covered in
[veilcore-midnight-testnet](https://github.com/hunterincoming/veilcore-midnight-testnet/blob/main/SECURITY.md).
